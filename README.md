### 🗄️ In-Memory KV Store — Storage from First Principles

![Storage & Networking](https://img.shields.io/badge/Storage%20%26%20Networking-1D4ED8?style=flat-square)

[![Source Code](https://img.shields.io/badge/Source%20Code-334155?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kunalkoshti/mini-redis-from-scratch)

A Redis-inspired database built in C++17, covering the path from TCP request handling to custom storage structures and key expiration.

- Implements a binary protocol, request pipelining, an edge-triggered epoll event loop, and defensive handling of partial or malformed requests.
- Uses an intrusive hash map with incremental rehashing, AVL-tree sorted sets, and a TTL min-heap scheduler.
- Explores throughput, tail latency, and cache behavior through benchmarks and Linux perf profiling.

### 🔄 Switchboard — Cooperative Concurrency Runtime

![Concurrency & Runtime Design](https://img.shields.io/badge/Concurrency%20%26%20Runtime%20Design-0F766E?style=flat-square)

[![Source Code](https://img.shields.io/badge/Source%20Code-334155?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kunalkoshti/Switchboard)

A runtime that schedules lightweight fibers within a single operating-system thread, exploring how tasks suspend, communicate, and resume execution.

- Implements custom x86-64 context switching, round-robin scheduling, cooperative blocking, and exception propagation across fibers.
- Provides a typed `Channel<T>` for unbuffered rendezvous and buffered message passing, with deadlock detection.

### 💬 Poll-Based TCP Chat Server

![Network Programming](https://img.shields.io/badge/Network%20Programming-92400E?style=flat-square)

[![Source Code](https://img.shields.io/badge/Source%20Code-334155?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kunalkoshti/poll_based_chat_server)

A TCP chat server that uses a single-threaded `poll()` event loop to accept connections, receive messages, and broadcast them to other connected clients.

- Manages multiple clients through I/O multiplexing, with a dynamically resized file-descriptor watchlist.
- Removes disconnected clients using an **O(1) swap-and-pop** operation, avoiding shifts through the watchlist.
- Provides a terminal-based chat workflow using Telnet or Netcat clients.

### 🏷️ Codeforces Tag Prediction — Multi-Label Text Classification

![Machine Learning & NLP](https://img.shields.io/badge/Machine%20Learning%20%26%20NLP-BE185D?style=flat-square)

[![Source Code](https://img.shields.io/badge/Source%20Code-334155?style=for-the-badge&logo=github&logoColor=white)](https://github.com/kunalkoshti/Codeforces_Tag_Prediction)

A machine learning pipeline that predicts algorithmic tags for competitive programming problems using problem statements and numeric metadata.

- Cleaned **9,238 problems** and filtered rare labels to form a dataset of **8,896 problems across 17 tags**.
- Combined **TF-IDF features with 1–5-grams** and scaled numeric features into a **65,570-feature sparse matrix**.
- Compared **Logistic Regression, Random Forest, XGBoost, and Linear SVM** using one-vs-rest classification, evaluating micro/macro F1, precision, recall, Hamming loss, and exact-match accuracy.
